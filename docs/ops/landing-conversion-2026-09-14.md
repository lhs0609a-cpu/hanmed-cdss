# 광고 랜딩 전환 개선

## 변경

- 첫 화면을 ‘처방이 고민될 때, 비슷한 치험례부터 찾아보세요’로 바꾸고 실제 치험례 검색 화면을 배치했다.
- 주 행동은 가입 없는 공개 증례 열람, 보조 행동은 무료 가입이다. 체험 직후에도 가입 및 게스트 진입을 제공한다.
- 공개 증례의 소견·변증, 처방·경과, 출처·검토를 키보드로도 탐색할 수 있다. 실시간 AI 분석이나 서비스 이용자의 성과로 표시하지 않는다.
- 반복 설명과 조형물 중심 근거/진료 흐름 섹션을 줄였다. 무료 범위를 먼저 설명하고 전체 요금제 및 결제 조건은 펼쳐서 비교한다. 치험례 전체 열람은 Basic 이상임을 명시한다.
- `/`, `/go`, `/start`, `/trial`이 같은 랜딩을 사용한다.

## 문헌 검증

이현진 외. 대한한방내과학회지. 2025;46(3):570–578.
https://doi.org/10.22246/jikm.2025.46.3.570

학회 PDF https://jikm.or.kr/upload/pdf/jikm-46-3-570.pdf 의 증례(571–572쪽), Table 1(572쪽), 치료 및 경과(573–574쪽)를 확인했다. 고정 요약은 200단어 이내다. 환자 식별 정보와 전체 원문은 복제하지 않는다. 복합 치료와 잔존 증상, 단일 증례의 해석 범위를 함께 표시하며 효능 보장이나 서비스의 임상 성과로 사용하지 않는다.

## 측정

- 기존 공개 클릭 이벤트의 `target`으로 `demo_start`, `demo_step_1`~`3`, `demo_next_1`~`2`, `demo_source_open`, `signup_after_demo`, `signup_free_plan`, `pricing_expand`를 구분한다.
- 세 항목을 모두 방문하면 `demo_completed`를 컴포넌트 방문당 한 번 기록한다. 탭 왕복으로 중복 기록하지 않는다.
- 가입 시작과 광고 UTM 연결은 기존 수집을 사용한다. 현재 관리자 가입 퍼널에 별도 데모 단계가 추가되는 것은 아니다.
- 이 배포 전후에는 문서 길이가 달라지므로 정규화 히트맵 좌표를 혼합해 비교하지 않는다. 날짜를 나눠 같은 유입 채널·기기에서 체험 완료, 가입 완료, 첫 기능 사용을 비교한다.

## 검증

웹 TypeScript 검사 통과. `scripts/landing-conversion-check.cjs` 로 320/390/1440px에서 가로 넘침 없음, 탭 방향키 조작, 원문 링크, 완료 이벤트 중복 방지, 월·연 요금 비교, 체험 후 가입과 UTM 유지, 광고 3개 경로 및 게스트 진입을 확인했다.

390px에서 체험 섹션 시작은 기존 1,162px에서 884px로 올라왔다. 기본 접힘 상태의 전체 페이지 높이는 6,273px이다. 이는 화면 구조 측정이며 전환율 개선을 입증하는 수치는 아니다.

스크린샷과 검사 결과: `output/landing-conversion/`. 검증 중 성장 분석 요청은 브라우저에서 가로채므로 운영 방문 통계에 테스트 이벤트가 저장되지 않는다. 계정 생성·결제는 하지 않는다.
