# SOURCE_CACHE — web

지침 V19 §K. **값을 적어 두는 파일이다.** 링크 모음이 아니다. 링크만 있으면 글을 쓸 때마다
재조회가 필요해 1편당 300초 이상이 든다. 여기 있는 값은 조회하지 않고 쓴다.

규칙
- 확인일이 90일을 넘긴 값은 쓰기 전에 재조회한다. ready.mjs 가 이것을 검사한다.
- 법·요율 개정 시행월이 지난 뒤 첫 글을 쓸 때는 A군 전체를 재조회한다.
- C군의 값은 **만들어 쓰지 않는다.** 조회하거나 §E-1 2·3단계로 처리한다.
- 글에 쓴 값은 출처명과 확인일을 본문 또는 그래픽에 함께 표기한다.
